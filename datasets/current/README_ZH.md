# 周期复合微板尺寸相关弯曲带隙与固定面积形状设计：数据与代码

**数据集版本 1.1.0。**

本数据集将图表、优化界面和原始计算记录整理在同一目录中。研究以钢–环氧单胞为数值算例，采用结合修正偶应力理论（MCST）、Reddy 三阶板运动学与逆因子化平面波法的模型。

作者：Xin Chen、Jun Cai、Alex Kalamkarov、Abdolhamid Akbarzadeh。

发布地址：[data-v1.1.0](https://github.com/Slight1211/mcst-tsdt-pwe/releases/tag/data-v1.1.0)。
代码仓库：[Slight1211/mcst-tsdt-pwe](https://github.com/Slight1211/mcst-tsdt-pwe)。

## 五组优化界面

五组当前设计均采用单胞尺寸 `a = 75 µm`、板厚 `h = 6 µm`、钢相面积分数 `0.09π`、Fourier 阶数 `N = 15`、48 个顶点与 6 个形状坐标、坐标边界 `b = 0.24`，以及 153 个波矢采样点。各内尺度从两种初始几何出发优化，报告收敛后相对带隙较大的结果。

| 环氧内尺度 `ell_um` | 153 点上的相对带隙，% |
|---:|---:|
| 0 | 34.58 |
| 0.5 | 34.31 |
| 1 | 33.22 |
| 2 | 27.05 |
| 5 | 2.96 |

在 `03_optimized_shapes/` 中查找对应内尺度的条目及其来源映射。顶点与频谱文件保留原数值精度，上表仅作经过舍入的导航摘要。初始界面为等面积正 48 边形。实体模型在 `ell_um = 1、2` 下，对初始界面和对应优化界面的 Γ、X、M 三点进行比较。表 2 的板模型数值采用表注所述的 45 点集，图 6 与五态形状摘要采用 153 点集；比较数值时需保留这一点集差别。

## 列名、单位与物理量

CSV 第一行为列名；JSON 记录求解设置与摘要；NPZ 存储 NumPy 数组。原始记录保留原列名和数组名。

| 列名或记号 | 含义与单位 |
|---|---|
| `ell_um` | 环氧材料内尺度，单位 µm；本组算例的钢相内尺度为零 |
| `a`、`h`、`r` | 单胞尺寸、板厚、圆形夹杂半径；单位以文件或映射说明为准 |
| `x_over_a`、`y_over_a` | 除以单胞尺寸后的顶点坐标，无量纲 |
| `kx_a`、`ky_a` | 波矢分量与单胞尺寸的乘积，无量纲；X 为 `(π, 0)`，M 为 `(π, π)` |
| `point` | 保存的波矢行编号，不是频率 |
| `Omega1`–`Omega6` | 排序后的无量纲模态频率，`Ω = 2πaf / sqrt(E_B/ρ_B)`；`B` 表示环氧基体 |
| `L`、`U` | 所述采样点集上的下、上带边，频率归一化方式见对应文件 |
| `J` 或相对带隙列 | `200(U − L)/(U + L)`，以百分数表示；`J_45` 指第 4、5 带之间的带隙，`J153_percent` 则指在 153 点上评价的数值 |
| 单位为 `pp` 的增益或带隙差 | 两个百分数相对带隙之差，单位为百分点 |
| `R_mc`、`R_sh` | 偶应力与经典剪切能量参与率，无量纲 |
| `S_ell`、`S_h` | 对数频率灵敏度 `∂ ln f / ∂ ln p`，无量纲 |
| MAC | 无量纲模态相关性；加权方式或物理场投影定义见来源记录 |

标注 Hz、kHz 或 MHz 的列为有量纲频率，与 `Omega` 不同。使用归一化公式时，各物理量采用 SI 单位。`kx_a = π` 也不同于已经除以 `π` 的横坐标。带符号相对间隔为负，表示所采样的两条频带发生重叠。

## 校验与复现

解压后，在数据集根目录运行：

```text
python 04_reproduction/verify_dataset.py --root .
```

文件清单为 `06_provenance/FILE_MANIFEST.csv`，文件哈希为 `06_provenance/SHA256SUMS.txt`。校验程序检查保存的文件，不启动数值求解。每张图表使用的输入和处理脚本可在图表映射中查找。

- **读取 CSV/JSON、核对哈希：**提供的完整性校验器仅需 Python 标准库。
- **处理已保存的频谱、场或图件：**按图表映射运行相应 Python 脚本及其依赖，涉及数组和绘图时使用 NumPy、Matplotlib；无需重新运行 COMSOL。
- **重新计算 PWE 频谱或优化形状：**使用对应求解脚本、NumPy、SciPy 与记录的参数，将结果写入新的目录。
- **建立或求解三维模型：**使用对应 Java/模型脚本，以及另行安装和授权的 COMSOL；位移场比较读取已有场数据或重新导出的场。

后续设计计算采用 Python 3.14.0、NumPy 2.4.3、SciPy 1.17.1 和 COMSOL 6.2.0.290；绘图环境记录 Matplotlib 3.10.8。原计算记录保留实际使用的软件版本，包括较早的 COMSOL 扫描环境。公开代码快照保留原相对目录结构，运行时按所选工作流的说明配置；不要在已归档的结果目录上直接执行历史控制脚本。新的计算应使用独立输出目录。
