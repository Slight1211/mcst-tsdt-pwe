# Composite microplate dataset 1.1.2

[Download the dataset](https://github.com/Slight1211/mcst-tsdt-pwe/releases/tag/data-v1.1.2)

The collection contains:

- Six main figures and three supplementary figures with their source data.
- Two main tables and seven supplementary tables, with displayed and unrounded values identified.
- Five optimized interfaces at material lengths 0, 0.5, 1, 2 and 5 µm, using `N = 15`, `b = 0.24` and 153 wavevectors.
- Spectra, modal fields, sensitivity checks, optimization records and three-dimensional comparisons.
- Six solid–solid MAC records for Table S5(a), their table comparison and verification tool.
- Numerical code, English and Chinese guides, source mappings and SHA256 checksums.

Start with the figure/table map or the directory for the required material length.
Use `CITATION.cff` for citation and `LICENSES.md` for licence scope.

Authors: Xin Chen, Jun Cai, Alex Kalamkarov and Abdolhamid Akbarzadeh.
Original data, figures and documentation: CC BY 4.0. Original executable code: MIT.

## 中文说明

数据集包含六张正文图、三张补充图、两张正文表、七张补充表，以及 `ell = 0、0.5、1、2、5 µm` 下的五组优化界面。五组设计统一采用 `N = 15`、`b = 0.24` 和 153 个波矢点。

支撑记录涵盖频谱、模态场、灵敏度核验、优化过程和三维比较。表 S5(a) 配有六份实体–实体 MAC 记录、表值核对结果和校验工具。数据包另含数值代码、中英文指南、图表映射、来源索引和 SHA256 校验值。可按图表编号或材料内尺度查找，引用与许可信息分别见 `CITATION.cff` 和 `LICENSES.md`。
